# Code of Conduct

## Our Pledge

We want this project to be an open, respectful, and welcoming environment for
researchers, engineers, students, and contributors of all backgrounds.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but communicate clearly.
- Give feedback on code and ideas, not on people.
- Share context when reporting bugs or proposing changes.
- Be patient with research-oriented or exploratory questions.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discriminatory language or conduct.
- Deliberate intimidation or exclusion.
- Publishing private information without permission.
- Repeatedly derailing technical discussion.

## Scope

This code of conduct applies to issues, pull requests, discussions, and other
project communication channels.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues,
or other contributions that do not align with this code of conduct.

For serious concerns, please contact the maintainers privately through
GitHub's private reporting form
(<https://github.com/spire-studio/pyfe4ai/security/advisories/new>, see
`SECURITY.md`); state in the title that the report is a code-of-conduct
concern rather than a vulnerability.
